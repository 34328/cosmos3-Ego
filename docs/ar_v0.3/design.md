# AR V0.3 设计

版本号：本文定义 **V0.3.0**。之后在此基础上的较大修改记为 V0.3.x，在本文末尾追加变更记录。

状态：三项基础实现及首轮20步已验收；2026-10-02 review 后增加前缀低噪声 DF，正在验证。正式训练尚未启动。

V0.3 以 V0.2 为基础，只改下面三项。动作表示（57D、PCA15、坐标系）、布局（C=4、K=8、H=15）、数据、clip 档位、联合 30 步推理全部沿用 V0.2，见 [../ar_v0.2/design.md](../ar_v0.2/design.md)。

| # | 改动 | V0.2 | V0.3 |
|---|---|---|---|
| 1 | 学习率与训练长度 | base 2e-5，action 五模块 5×；1000 步；cosine 降到 10% | **全模型 1e-4**（五模块倍率 1）；**3000 步**；cosine 降到 **30%** |
| 2 | 因果训练策略 | teacher forcing：干净 GT 历史 + 噪声目标，两遍前向 | **diffusion forcing**：逐块 σ，随机低噪声前缀，单遍前向，历史就是带噪的前面几块 |
| 3 | action loss 权重 | 57 维统一 MSE | **手腕平移和旋转加权** |

定位：官方 Nano 权重是双向的（`video_temporal_causal=False`），本身没有 AR 能力。V0.3 把因果改造当作一次"继续预训练"，所以学习率更大、训得更久。

**注意**：三项同时改，V0.3 和 V0.2 的差异不能拆到单一因素。第 1 项已有单因素参照，见下。

**1e-4 单因素对照（V0.2 框架，1000 步，2026-10-01）**：pred_history 误差下降约 18–21%，oracle 也改善；但 video loss 与 2e-5 持平（0.132 对 0.131），视频运动方向余弦没有提高（验证集 gt 0.035，2e-5 为 0.104，同一口径）。在训练集 16 个窗口上余弦也只有 0.18（过拟合组 300 步为 0.94），说明 1000 步时模型连训练分布都没学到运动方向，是**欠拟合**，不只是泛化问题。这支持 V0.3 加长训练。

## 1. 学习率与调度

| 项 | 值 |
|---|---|
| 峰值 lr | 1e-4，全模型统一（`action2llm / llm2action / action_modality_embed / action_state_embed / vision_condition_embed` 倍率均为 1） |
| 依据 | 官方 `vision_sft_nano.toml`：Nano 全量微调 lr=1e-4，注释写明扫参后 1e-4 比 2e-5 收敛快 |
| 调度 | 官方 `LambdaCosine`：warmup 100 → cosine，`cycle_lengths=[3000]`、`f_max=1.0`、`f_min=0.3` |
| 终点 lr | `f = f_min + 0.5(f_max−f_min)(1+cos πt)`，t=1 时为 0.3，即 3e-5 |
| 步数 / 保存 | 3000 步；每 500 步保存 |
| 并行 | 双节点 HSDP，shard 8 × replicate 2，NCCL 走内网 TCP |

## 2. Diffusion forcing：可行性分析

### 2.1 官方怎么做

官方 `causal_training_strategy="diffusion_forcing"`（`omni_mot_model.py`、`omni_mot_causal_model.py`）：

- 训练：每个视频 latent 帧独立采样 σ，形状 `[B, T_max]`；单遍前向，因果掩码，每帧看到的历史就是同一遍里**带各自噪声**的前面帧；条件帧 σ=0。
- 推理：已生成的帧写入 KV cache 时，按 `sigma_diffusion_forcing`（默认 0.02）加一个小噪声再写入。官方注释：DF 训练时 σ 从不为 0，所以完全干净的上下文对模型是分布外输入。

### 2.2 我们已经具备的部分

| 需要的能力 | V0.2 现状 |
|---|---|
| 每块独立 σ | **已有**。`EgoVerseARV02Model._get_train_noise_level_vision` 已按块采样独立 σ，块内 4 个 latent 共享；action 同样按块独立（`_add_noise_to_input`） |
| 块级因果掩码 | **已有**。`joint_mask_mod(noisy=False)`（V0.2 的 clean pass 掩码）：每块看本块 + 前 15 块，U/S 只看本块条件。这正是 DF 需要的掩码 |
| 推理时历史写入加噪 | **已有**。V0.2 历史加噪对照实现了 `history_video_sigma`，在块生成完、写入历史 KV 时加噪；需扩展到 action |
| 每 token 独立 timestep | **已有**。`uses_single_timestep=False` 路径 |

### 2.3 需要改的部分

1. **训练改为单遍**：不再跑"干净历史 pass + 噪声目标 pass"两遍，只跑一遍带噪序列，掩码用 `noisy=False` 那套块因果规则，所有块都算 loss。
   - 计算量预计约为 V0.2 的一半（V0.2 的 clean pass 带梯度）。实际速度以短测为准。
2. **注意力类**：新增单遍版本，复用 `joint_mask_mod(noisy=False)`；不改 V0.2 的 `JointTeacherForcingAttention`。
3. **推理**：每块去噪结束后，以 σ_small 对**视频和 action** 一起做 refresh 写入历史。σ_small 默认 0.02；按2026-10-02最新要求，短测 checkpoint 与正式评测均扫 **{0.02, 0.05, 0.1}**。
4. **U_k / S_k 保持干净**：与官方"条件帧 σ=0"一致。pred_history 归因显示动作漂移部分来自块首条件，U/S 加噪留作 V0.3 之后的单独对照，本版不做。

### 2.4 风险

| 风险 | 说明 | 应对 |
|---|---|---|
| 训练信号变弱 | 块 k 的历史可能是高噪声，单块学到的条件信息比 TF 少 | 3000 步、1e-4 部分补偿；对照看 gt 模式单块误差有无明显退步 |
| 训练/推理 σ 分布不一致 | 原每块 waver/logitnormal+shift5 常为重度加噪，紧前块作为历史时近干净情况稀少 | 使用2.5节前缀低噪声采样，并扫推理 σ_small |
| 首块 | 块 1 前面只有 U_1/S_1，与 TF 相同 | 无需特殊处理 |
| 联合 action | 官方 DF 的 action σ 是每样本一个标量；我们已按块独立，不走官方这条分支 | 沿用 V0.2 的按块 action σ |

**结论：可行。** 主要工作是"去掉 clean pass，单遍前向复用块因果掩码"，以及推理端 refresh 改为带 σ_small。不需要改官方框架代码。

### 2.5 前缀低噪声 DF（2026-10-02 review 修订）

单遍下，块 k 的带噪目标同时是后续块的历史。沿用的视频 waver+shift5 抽样偏向大 σ（用户 review 实测中位数约0.83、P(σ<0.1)约1%），推理 refresh σ_small 则接近干净。为增加训练时近干净历史覆盖，默认启用以下采样：

- 每个样本按真实块数 n_chunks，独立抽 `L ~ Uniform{1,...,n_chunks}`；L=1 表示没有低噪声前缀。
- 块编号从1起。块 `< L`：每块抽 `σ ~ U(0, σ_hist_max)`，默认 **σ_hist_max=0.1**；该块视频和 action 同取此低噪声 σ，分别按各自官方时间标度路由 timestep。
- 块 `≥ L`：视频仍为 waver+shift5，action仍为 logitnormal+shift5。先照旧完成原抽样，再覆盖前缀；独立随机数生成器不改变原抽样顺序或全局 RNG 状态。
- 前缀开关与 `sigma_hist_max` 为显式配置项，默认开启/.1。关闭时与前缀改动前的 V0.3 σ/timestep/后续 RNG 序列逐位一致。
- U_k/S_k 仍为σ=0；全部非条件块照常计算 loss，不因前缀改变而屏蔽。
- 独立 RNG 必须可按 seed、训练 iteration 与数据并行 rank 复现，不增加未经 checkpoint 管理的持久随机状态；不同样本/迭代独立。

此前讨论的 `0.5·u²` 已由用户更正为均匀 **U(0,0.1)**，不进入默认实现或正式配方。抽1万个样本的直方图按三种口径报告：①前缀内（理论全部σ<.1）；②每个块（近干净比例随块位置下降）；③所有后继块的紧前一块历史位置（排除每个样本末块），约50%加上保留原分布的少量低σ。均匀分界L给出的低噪声前缀在全体历史位置期望占比正好50%，不能声称每个块都为50%。

修改后重做CPU/GPU单测及单节点20步，记录实际逐块σ、loss、显存和与V0.2两遍实测耗时。新短测 checkpoint 先对heldout8做 gt/generated ×三σ，共48份结果；用户确认后，正式第500/1000/2000/3000步每点 heldout8 gt/generated、train16 gt各扫三σ，共96份结果。

## 3. 手腕加权

V0.2 的 `whole_action_flow_loss` 是 57 维统一 MSE，并断言不允许子块加权。V0.3 新增一个 57 维通道权重向量 `w`：

```
loss = Σ w_c · keep · (pred − target)²  /  Σ w_c · keep
```

分子分母同时乘 `w`，总 loss 尺度不随权重变化；默认全 1 时与 V0.2 逐位一致（需单测）。

| 字段 | 维度 | V0.2 占比 | V0.3 权重 | V0.3 占比 |
|---|---|---:|---:|---:|
| 相机平移 + 旋转 | 9 | 16% | 1 | 10% |
| 右腕平移 + 旋转 | 9 | 16% | **3** | **29%** |
| 右手形 PCA | 15 | 26% | 1 | 16% |
| 左腕平移 + 旋转 | 9 | 16% | **3** | **29%** |
| 左手形 PCA | 15 | 26% | 1 | 16% |

占比按维度数 × 权重估算（加权总维数 93），未计各通道实际误差大小。V0.2 中手形 30 维占了一半以上的 loss，手腕只占 32%；V0.3 手腕升到约 58%。
权重 3 是起点值，不是调过的值。各通道已经过 Piecewise-Asinh 归一化，尺度可比。

## 4. 验收

同 8 个 heldout 窗口、seed 42、联合 30 步，对照 V0.2 step1000 与 1e-4 单因素组：

1. 视频运动：光流**方向余弦**（V0.2 heldout 约 0.05），幅值比接近 1；
2. generated 模式第 1–17 块的逐块误差曲线是否仍持续上升；
3. gt 模式双腕块末误差是否低于"不动"基线（44.7 / 59.7 mm）；
4. 视频里的手与预测 action 投影一致，不能靠画面静止刷低数字。

第 500 / 1000 / 2000 / 3000 步各评一次 gt 和 generated，看是否仍在改善。每次同时在训练集 16 个固定窗口（过拟合组清单）上评 gt，跟踪训练分布上的方向余弦，判断是否仍在欠拟合。

光流口径统一用 V0.2 experiment 第 15.2 节的"320×180 整体余弦"，不与更早的口径混用。

## 5. 待确认

- 手腕权重 3 是否合适：先看 V0.3 训练中各字段 loss 曲线再决定是否调整。
- σ_small 的最终取值：由评测扫描决定。
- 是否同时开 MoBA（官方双向步/因果步交替，保住预训练能力）：本版不开，作为后续候选。
