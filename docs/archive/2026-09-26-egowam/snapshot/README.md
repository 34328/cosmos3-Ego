# cosmos3-Ego

Experiments built on NVIDIA Cosmos 3 for EgoVerse egocentric video generation
and joint hand-pose prediction.

## Projects

- `cosmos3_joint_video_hand_pose/`: joint video/action training, artifacts,
  replay visualization, and experiment configs.
- `cosmos3_egoverse_it2v/`: EgoVerse image-to-video experiments.
- `packages/cosmos3/`: the pinned Cosmos 3 source used by the experiments.

Runtime outputs, checkpoints, W&B caches, local manifests, tests, and training
data are intentionally excluded from Git. See each project directory for its
experiment documentation and launch scripts.
