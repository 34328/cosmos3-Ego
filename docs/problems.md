# AR 联合模型共用问题清单

更新：2026-10-02。适用于 AR V0.1 / V0.2 / V0.3 / V0.3.1；后续版本继续维护本文件。原 [V0.2 问题清单](ar_v0.2/archive/problems_2026-10-01.md) 作为历史判断保留，最新状态以本页和各版本实验记录为准。

## 当前范围

当前优先解决**视频生成质量**：先让真实条件下的短段画面与手物运动可靠，再处理长序列的历史误差累积。

action 策略、57D/PCA15 表示、坐标系及模型架构暂时固定；C4/K8/H15 和联合生成方式沿用现有方案。这里的“固定”是保持方案，不是新增 action 参数冻结。已有 V0.3.1 对照按其获批配方解释，不能借排查视频再叠加 action 改动。

action 的腕误差、手形与视频中的手是否一致仍作为联合生成的观察项；优先级调整不等于已经证明 action 没有独立问题。原清单中的相机投影、积分漂移等保留为后续问题，暂不单独展开。

一次只推进一个问题：先复用存档和既有评测，只有证据缺口明确时才补最小验证；需要正式训练时另行确定单因素方案。

这些是质量现象，不是单因素因果结论。V0.2 与 V0.3 的训练步数、调度、监督和历史噪声不同；尚不能把差异全部归到 DF。V0.3 已采用单遍 DF，旧清单“DF尚未开启”已过时。

## 视频问题与处理顺序

| 顺序 | 要回答的问题 | 优先复用的证据 / 最小下一步 | 判定与后续 |
| --- | --- | --- | --- |
| **V1 · 当前** | **给定真实条件时，短段视频能否生成好？** 手、物体和背景从何时开始失真，运动是否从第一块就偏了？ | 使用既有 gt / generated 存档与统一网页：先看无跨块历史的第一块，再看每块真实条件重置后的短段。区分纹理破碎、手物形变与运动轨迹错误；展示固定的 train / heldout pick-and-place 窗口，不另挑好样本。 | 第一块或 gt 模式已经差，先处理短段生成；短段可靠而 generated 中后段变差，再进入 V3。gt 的后续块仍含历史，只能辅助定位，不能当成完全独立单块实验。 |
| **V2 · 排队** | **为什么运动没有学好？** 监督分配、训练覆盖或条件利用是否限制了目标块学习？ | 先消化已有 V0.3.1 同步数、同窗口、同σ对照：它仅去除前缀视频/action loss分子，保留原分母与历史梯度。结合 train16 和 heldout 结果区分训练分布拟合与泛化现象。 | 用画面、方向余弦、幅值比和PSNR判断；不以总loss回到0.13验收。只有结果指向某个因素时，再定下一项视频侧对照，不同时改采样、数据和优化。 |
| **V3 · 排队** | **为什么连续生成逐渐漂移？** | 在同checkpoint、同窗口和同σ下对照 gt / generated 的既有逐块曲线及长视频，找偏差开始扩大的位置；复用已有三档σ结果。 | 观察从早期到第17块的增量退化，避免把首块已有误差都算成历史累积。涉及缓存噪声等设置时一次只动一项。 |
| **V4 · 排队** | **块边界跳变来自预测重置，还是解码/时间对齐？** | 从已有视频检查边界前后。gt 重置造成的跳变与 generated 自身不连续分开记录；确认原始时间轴、逐块解码及条件帧的展示口径。 | 只有边界问题在短段质量改善后仍独立存在，才单独处理。不用插帧、平滑掩盖生成问题。 |

V1 首轮只形成一页简短结论：固定窗口中“哪一类错误、最早何时出现、gt与generated是否同样出现”。已有官方整段 image2video 结果可作视觉参考，但生成时域、解码方式和条件不同，不能据此判定“训练损伤了Nano”。官方双向起点的零样本AR也不是经过AR训练的上限。

## 共同评判口径

- **画面与交互**：固定 train / heldout 各三窗的 pick-and-place 展示，短片看完整操作，长片看完整17块；复用 [统一可视化规范](../cosmos3_joint_video_hand_pose/visualization/README.md)。这六窗用于解释现象，不替代冻结 heldout8 / train16 的定量比较。
- **运动**：沿用 [V0.2 实验第15.2节](ar_v0.2/experiment.md) 的320×180整体光流口径，跨窗口/块先合并点积与平方范数再求余弦；幅值比为生成/GT，零范数记null。余弦接近0说明该指标下运动一致性低，不能单凭它证明运动随机或定位原因；相机、背景运动也会影响全图指标。
- **画质**：PSNR先合并MSE再换算；结合视觉检查，不能由PSNR推出方向正确或交互合理。幅值比接近1也不等于运动轨迹正确。
- **对照**：固定窗口、seed、采样步数、history模式与σ；注明checkpoint步数、训练集/heldout和原始时间轴。V0.2历史σ0与V0.3三档不可隐去。
- **结论**：保留负结果；像素差分“57%运动幅度”、由有限时移扫描推断“精确滞后4帧”、前缀“不可学习的噪声”、V0.3“持续越训越差”均不作为当前依据。MoBA或其他注意力结构改动暂不纳入本轮，也不把某个官方开关预设为质量修复。

后续每完成一项，只更新该项的证据、结论和状态；详细结果写入对应版本的 experiment.md，避免重复维护多份问题清单。
