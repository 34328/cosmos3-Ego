# 纯视频 AR 的当前问题

适用项目：Cosmos3-Nano AR IT2V；不含 action。当前基线是完整segment、官方75008 token动态packing的 V0.2，已完成1500步。设计和原始证据见 [设计](ar_it2v_v0.2/design.md)与[实验记录](ar_it2v_v0.2/experiment.md)。

## 已确认的现象

- 只用首帧＋文本的自由生成仍会偏离操作任务，长片误差累积；完成训练不等于画质或任务完成率已通过。
- 改用已完成GT块作为Transformer历史后，用户观察到任务完成与幻觉有改善；这说明历史误差值得关注，但不是对全部失败原因的定量归因。
- 随后的干净GT历史验证（历史σ=0、匹配GT解码前缀，train/test各两段、83个预测块）仍见单块手部停滞、运动偏离和细节变形。整体块内运动方向cos为0.114–0.483，两段像素误差不及复制上一GT帧的静止基线；不能假设单块动作已学好、仅有累积误差。指标包含相机/背景及VAE重建影响，具体证据见实验记录。
- 同一预测在完整GT前缀下解码，比拼接预测前缀解码减少了短片中的重影；GT连续VAE重建平稳。由此支持解码历史不匹配是一个来源，但仍有块间跳变。
- 将上一预测末latent加成锁定边界条件，在已试的完整短片中出现停滞和偏离，没有改善；不采用为默认。

## 当前使用的口径

自由生成保留自身预测KV与整段预测连续解码。真实历史诊断同时匹配Transformer的GT历史和VAE的GT解码前缀，按绝对时间裁出各预测块再拼接；它依赖GT，不能当作自由生成结果。旧GT视频仍按其原解码模式标记，不改名冒充新产物。

曾错误使用官方首帧编码优化提取GT历史，导致未来latent填零；这批产物已标为无效并撤出页面，不能作为模型能力证据。修复和有效产物来源保留在实验记录。

## 后续工作边界

2026-10-05 用户确定先解决自生成历史下的累积误差；GT-history 拼图的块间跳变暂放，不继续边界锁定或解码拼接试验。

随后用户要求先验证单块能力，暂缓上述训练方向；干净GT历史结果未支持“单块已正确”的前提。后续方案需同时考虑单块运动预测不足，不据此直接启动自身历史训练。

首轮候选为小规模自身历史监督微调，从 V0.2 step1500 延续模型权重，另开实验，保留旧基线。它改变训练历史来源，不是只屏蔽前缀 loss：从首帧＋文本出发，各历史块必须从纯噪声实际采样，完成后写入该样本自己的 KV，后续目标块在这份历史下训练。目标块仍用 GT 加噪与原生 flow 监督，先考虑截断已生成历史的梯度，控制计算和显存成本。训练历史不得由一次带噪 GT 前向的 x0 估计冒充，也不得在块结束后换回 GT。

这是一种待验证的监督对照，不等同完整 Self Forcing：模型历史已偏离真实轨迹时，GT 下一块监督可能产生冲突，不能预先声称已解决误差累积。[Self Forcing 论文](https://arxiv.org/html/2506.08009v1)及其[官方实现](https://github.com/guandeh17/Self-Forcing)采用少步初始化、自身历史 rollout 和整段分布匹配监督；Wan 的权重、文本及 VAE 接口不能直接用于 Cosmos3 I＋T。

复用边界：现有 `cosmos3_ar_it2v/inference.py` 的分块、绝对时间和整块 KV refresh 语义可保留，但 `generate_latents` 是单样本、无梯度的推理入口，不能直接充当训练接口。本地框架中的 `DMD2RFModel._backward_simulation` 是整段同步降噪，不是逐块自身历史；只能按需要复用 flow 转换、优化器及 checkpoint 等组件，不另造 Trainer。VAE、数据与文本配对、C4/local16、末块权重和样本间隔离保持原基线定义。

先选少量短的完整 segment 做成本与质量对照，不截取动作中段、不重跑全量扫描。验收以同首帧、文本、seed及采样设置的自由生成前后段任务保持、场景/物体漂移和视频可视结果为主；GT-history 只作参考，不用总 loss 判断成功。实际学习率、更新数、采样步数、历史梯度和资源配方在实现短测后确认，新正式训练尚未获批准。

暂不启动新训练、不重复已完成的大规模扫描；具体实验由用户选定后执行。统一预览约定见 [可视化README](../visualization/README.md)。
